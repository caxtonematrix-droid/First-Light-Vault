## 🌒 Prologue — Why Another Trainer Exists

There is a moment, somewhere between the title screen and the first mission briefing, where every player realizes the same quiet truth: *the game is faster than your reflexes*. **007 First Light — Cinematic Trainer Companion** was born from that exact moment.

Rather than treating training as a cheat sheet, we treat it as a **cockpit**. Think of this repository as the instrument panel of an aircraft you already own but haven't learned to fly yet. Every toggle, every slider, every numeric readout is designed to be read at a glance during a firefight, a stealth infiltration, or a high-speed chase — without pulling you out of the scene.

This project is a **standalone companion utility** — a companion process that observes and augments your single-player session in real time. It does not replace game files, does not patch binaries, and does not touch online infrastructure. It is a training wheel for a motorcycle you are determined to ride without training wheels someday.

> *"The name is a promise. First Light means the beginning of clarity — not the end of challenge."*

## 🎯 Concept & Design Philosophy

Most training utilities are built like a Swiss Army knife taped to a sledgehammer — dozens of options, zero coherence. We chose the opposite path. **Every control must justify its pixel.**

Three design laws govern this repository:

1. **Peripheral vision first.** A trainer is only useful if you can operate it while watching the game. Controls are grouped by tactical context (movement, combat, stealth, vehicle), not alphabetically.
2. **Reversible by default.** Any adjustment made during a session reverts automatically when the companion closes. Nothing lingers, nothing persists unless you explicitly save a preset.
3. **Zero narrative interference.** The overlay never covers cutscenes, never steals frame focus, and never injects text into cinematic sequences. Story is sacred.

The visual language borrows from cinematic HUD design — thin typography, restrained accent colors, and motion that eases rather than snaps. It should feel like a piece of MI6 equipment, not a debug console.

## 📱 Responsive Interface Architecture

The companion window is not a fixed rectangle. It is a **flowing layout** that reshapes itself around your monitor topology and in-game HUD density.

- **Ultra-wide monitors** — panels dock to the lateral dead zones, out of sightline.
- **Single-monitor setups** — the overlay compresses into a vertical ribbon.
- **Multi-monitor rigs** — a dedicated control surface moves to the secondary display.
- **Windowed and borderless** — full DPI awareness from 100% to 250% scaling.
- **Touch and pen** — optional tablet mode for configuration sessions outside the game.

Every panel animates at 120 Hz target with graceful fallback to 60 Hz on older hardware. Layout transitions use spring easing so the UI never feels like it is catching up to your input.

## 🚀 Installation & First Run

Getting the companion running is a three-beat process, not a scavenger hunt.

1. **Acquire the artifact.** Use the distribution macro shown above to obtain the latest 2026 build for your platform.
2. **Extract to a stable path.** Place the companion folder outside your game directory — the two should be neighbors, not roommates.
3. **Launch the game first, then the companion.** The companion attaches to a live session only; this ordering is deliberate.
4. **Acknowledge the sandbox check.** On first launch, the wizard confirms your game mode is single-player before enabling any control.

If anything goes wrong, the built-in recovery mode resets the companion to its factory state in under five seconds.

## 🛠️ Configuration Reference

The companion persists settings in a human-readable profile file, so power users can diff, version, and share configurations.

Key configuration groups:

- **Profiles** — named bundles of settings, one active at a time.
- **Keybinds** — global hotkeys with conflict detection and reassignment suggestions.
- **Overlay** — opacity, scale, anchor corner, and animation speed.
- **Toggles** — default state for each feature group on session start.
- **Telemetry** — sampling rate, retention window, and export format.

Every key is documented inline with its valid range and default value, so reading the profile file is itself a form of documentation.

## 📈 Performance & Telemetry

The companion is engineered to be invisible to your frame budget.

- **Sub-1% CPU overhead** at idle, measured across three hardware tiers.
- **Zero additional GPU draw calls** — the overlay composites through the desktop window manager.
- **Input latency budget** under 4 ms for all toggle actions.
- **Memory ceiling** of 180 MB including session logging.
- **Optional telemetry** is local-only and exportable; nothing is transmitted automatically.

A dedicated diagnostic panel graphs frame pacing over the last sixty seconds, which is invaluable when tuning settings on constrained hardware.

## 🔐 Security & Integrity

Trust is a currency, and we spend it carefully.

- **Signed builds** — every release is cryptographically signed and verifiable.
- **Source transparency** — the repository history is public and auditable.

## ❓ FAQ

**Does this work in online multiplayer?**
No. The companion is designed and gated for single-player sandbox sessions only.

**Will my saves be modified?**
No. The companion operates in memory and never writes to save files.

**Can I run it on a laptop with integrated graphics?**
Yes, with the overlay set to compact mode. The companion scales down gracefully.

**How do I revert everything?**
Close the companion. Settings revert automatically unless you saved a preset.

**Is there a portable mode?**
Yes — place a marker file next to the executable and all configuration stays local.
